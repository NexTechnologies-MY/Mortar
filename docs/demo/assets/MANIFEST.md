# Deck Assets Manifest

Every image the pitch deck uses lives here. `shot-*` files are screenshots of
the deployed product captured with Playwright at 1440 px in the light theme on
the clean post-reset dataset; `art-*` files are generated illustrations
following `docs/DESIGN.md` (monochrome ink and paper, the brand `#c2410c` as the
only accent, no text, no logos, no people).

## Product Screenshots

- `shot-landing.webp` — the public landing page, hero and panel.
- `shot-chase.webp` — the `/chase` list for Sales Admin, `BK-9001` on top with
  Jev's suggested next action and the Create Task control.
- `shot-case.webp` — the `/bookings/BK-9001` case page: header, stage, risk chip
  and the loan and legal tracks.
- `shot-proposal.webp` — Jev's proposal on the banker's payslip message
  (Documents Requested, Payslip, Loan Admin) with its Confirm, Dispute and
  Dismiss controls, cropped tight to the proposal box.
- `shot-forecast.webp` — the `/forecast` page for Finance: expected signings,
  stage conversion rates, the accuracy check and the assumptions panel.
- `shot-backtest.webp` — the Accuracy Check card on `/forecast` (predicted
  against observed, Brier score, calibration), cropped to the card.
- `shot-settings.webp` — the `/settings` page: Demo Data card, Reset Demo Data
  and Jev status.
